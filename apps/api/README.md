# API NestJS — subetapa 1.4

Backend ejecutable en Node.js 24. Desde la raíz: `npm ci --ignore-scripts`, `npm run api:build`, `npm run api:setup`, `npm run api:start`.

La infraestructura y las migraciones deben estar listas antes de api:setup. Instrucciones completas: [SUBETAPA-1.4.md](../../docs/SUBETAPA-1.4.md). Arquitectura: [API.md](../../docs/API.md).

Tras modificar TypeScript, detener la API, ejecutar api:build y volver a iniciarla. dist/ y el cliente generado no se versionan.
